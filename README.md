## 🚀 Sobre o Projeto  

O **GYM HUB** é uma aplicação desenvolvida para centralizar e organizar informações relacionadas ao mundo fitness 🏋️‍♂️  
O objetivo é oferecer uma experiência simples, moderna e eficiente para gerenciamento de treinos, usuários e desempenho.

---

## ✨ Funcionalidades  

- ✅ Cadastro de usuários  
- 🔐 Login e autenticação  
- 🏋️ Gerenciamento de treinos  
- 📊 Acompanhamento de desempenho  
- 🎨 Interface moderna e intuitiva  
- ⚡ Sistema organizado e escalável
